# 📊 Sales Performance Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive sales performance dashboard developed in Microsoft Power BI.

The main objective is to transform raw sales data into clear and useful insights to support business decision-making.

The project includes data cleaning and transformation, KPI analysis, data visualization and interactive dashboard development.

---

## 🎯 Business Questions

The dashboard was designed to answer the following questions:

- How are total sales evolving over time?
- Which products generate the highest sales?
- Which regions have the best performance?
- What is the relationship between sales, costs and profit?
- Which areas represent the best business opportunities?
- How does performance vary across different periods?
